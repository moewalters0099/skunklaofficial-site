Editorial dashboard

The content editor is installed. GitHub login uses the configured production OAuth credentials. Only authorized GitHub accounts may access the editor. Until authentication is connected, this is not an active admin account.

Remaining setup

  1. Register an OAuth application with GitHub.
  2. Configure a secure OAuth service and its private credentials.
  3. Authorize the intended administrator's GitHub account for repository access.
  4. Test article creation and automatic publishing end to end.

Never enter GitHub passwords, access tokens, or OAuth secrets into this public website or repository.
